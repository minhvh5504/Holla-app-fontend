## 🎯 Prerequisites

### 📌 System Requirements
Before running the project, ensure you have the following installed:

- [Node.js](https://nodejs.org/) (LTS version recommended)
- [React Native CLI](https://reactnative.dev/docs/environment-setup)
- [Java Development Kit (JDK)](https://www.oracle.com/java/technologies/javase-downloads.html) (version 11 or later)
- [Android Studio](https://developer.android.com/studio) or [Xcode](https://developer.apple.com/xcode/) for iOS development
- A virtual device (Emulator) or a physical device with **USB Debugging** enabled

## 📥 Installation & Running the Project

#### 1️⃣ Clone the project from GitHub
```sh
git clone https://github.com/minhvh5504/Holla-app-fontend.git
cd Holla-app-fontend
```
#### 2️⃣ Install dependencies
```sh
npm install
```
## 📱 Running on a Device

#### ✅ Check connected devices
```sh
npx react-native doctor
```
#### 📱 Run Metro bundler
```sh
npx react-native start
```
#### ▶️ Run the app on Android
```sh
npx react-native run-android
```
#### 🍎 Run the app on iOS (macOS only)
```sh
cd ios
pod install
cd ..
npx react-native run-ios
```
